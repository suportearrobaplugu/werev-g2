# 09 · Frases-Ouro

Frases consolidadas da metodologia. Usar em slides, copy, posts, headlines, encerramento de e-mail, fala de palco.

**Regra de uso:** use as autorais antes de inventar nova. Se a frase certa para o momento já existe aqui, use-a. Frases são ferramenta de coesão — quando o cliente ouve a mesma frase 3 vezes em momentos diferentes, vira marca registrada.

## Diretrizes de uso

### Para slide

Frases curtas (3, 6, 8, 9, 11, 20, 21, 23, 28) cabem bem em slide-mãe ou abertura de bloco. Não acumule mais de 1 frase por slide.

### Para copy de post/anúncio

Frases provocadoras (8, 9, 10, 17, 22) servem bem como headline ou primeira linha de copy. Termine com pergunta de diagnóstico ou CTA do material correspondente.

### Para fala de mentor / discovery

Frases reflexivas (13, 14, 15, 19, 25) abrem conversa com sócio/gestor. Use depois de uma pergunta — não jogue a frase no vácuo.

### Para conteúdo educativo / artigo

Frases-tese (1, 5, 6, 11, 30) ancoram o argumento central. Use no parágrafo de abertura ou no fechamento.

### Evite

- Empilhar mais de 2 frases na mesma seção (perde força).
- Usar frase autoral em contexto onde ela não se aplica só pra encaixar (soa forçado).
- Trocar palavras das frases canônicas (perde reconhecibilidade — "tá" não vira "está", "pra" não vira "para" quando o texto é fala/copy informal).
